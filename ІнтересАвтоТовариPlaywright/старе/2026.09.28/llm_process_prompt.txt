З цього польського тексту визнач інформацію про запчастину грузового автомобіля.

Потрібні тільки ці поля:
NameRu — назва деталі російською мовою.
NameUa — назва деталі українською мовою.
CommentUa — важлива інформація про деталь українською мовою.
CommentRu — важлива інформація про деталь російською мовою.
Size — розмір деталі, якщо він є. Якщо розміру немає, залишай це поле пустим.

ПРАВИЛА ПЕРЕКЛАДУ ТА АДАПТАЦІЇ (ВАЖЛИВО):
1. Не перекладай польський автосленг буквально. Замінюй специфічні терміни загальноприйнятими технічними назвами:
   - "Atrapa" (у контексті авто) -> перекладай як "Капот" або "Решітка радіатора" (НЕ муляж, НЕ імітація).
   - "Lampa" -> залежно від контексту "Фара" або "Ліхтар".
   - "Paka" / "Buda" -> "Кузов" / "Вантажний відсік".
2. Назву деталі (поля NameRu та NameUa) формуй строго у вигляді:
   іменник-прикметник-іменник-прикметник (наприклад: "Трос замка капота", "Комплект ремонтний клапана керування").
3. Коментарі (поля CommentUa та CommentRu) мають бути максимально короткими, стислими та БЕЗ OEM-номерів. Використовуй загальноприйняті скорочення для сторін (лів. / прав.), брендів, моделей у дужках та років випуску. 
   Приклад: "лів. DAF(XF106) від 2013р" або "прав. MAN(TGX, TGM) Euro6".
4. Не вигадуй інформацію, якої немає в тексті або яка не випливає з моделі запчастини.

ФОРМАТ ВИВЕДЕННЯ ТА ОБМЕЖЕННЯ:
Виведи тільки заповнений шаблон нижче. Будь-який текст, коментарі, посилання, поради чи запитання після поля Size суворо заборонені. 
Зупини генерацію одразу після заповнення значення Size (або після двокрапки, якщо поле пусте).
